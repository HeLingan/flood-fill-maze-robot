# Flood Fill Maze Robot

基于 Python 的机器人模拟器：在未知的 8×8 网格迷宫中，仅通过局部墙壁感知进行探索，并采用从目标出发的反向广度优先搜索（BFS）实现洪水填充（flood-fill）路径规划。

维护者：Lingan He。项目在 AI 辅助下开发。

## 工作原理

- `Maze` 保存完整的真实迷宫；`KnownMaze` 保存已观测的边。机器人初始只知道迷宫尺寸、起点、目标和外边界，每次仅感知当前单元格的四条边。
- 规划时采用乐观假设，将未知边视为可通行。每次观测后，反向 BFS 都会基于这张乐观地图重新计算完整距离场；由于边可双向通行且每步代价均为 1，因此可以从目标反向搜索。
- 每次移动只跨越已确认为 `OPEN` 的边，进入距离值小 1 的相邻单元格。多个方向满足条件时，按东、南、西、北的顺序选择。
- 到达目标后停止探索；若当前单元格在乐观地图上也没有通往目标的路径，则判定目标不可达并停止。该判定在本项目的模型假设下成立。

## 环境要求与使用

Python 3.9 及以上版本，仅使用标准库。图形界面需要 Tkinter、可正常工作的 Tcl/Tk 安装及图形桌面环境。在仓库目录下运行：

```sh
python3 main.py
```

Windows 下可用 `py` 替代 `python3`。界面提供 **Step**（单步）、**Run/Pause**（运行/暂停）、**Reset**（重置）及预设地图选择。

- `open`：演示无障碍导航。
- `detour`：演示发现隐藏死路后的回退与重新规划。
- `blocked`：演示对被墙包围、不可达目标的判定。

## 测试

```sh
python3 -m unittest -v
```

10 个测试方法覆盖预设地图的运行结果、局部感知的信息边界、边的对称性、矛盾观测、起点与目标重合、起点被封闭、非法目标及终止状态行为。逐步检查验证移动安全性与状态一致性。其中两个方法分别包含 24 个固定种子子案例（将完全已知地图上的距离与独立 Dijkstra 结果比较）和 30 个固定种子子案例（将探索结果与真实可达性比较）。这些子案例不一定对应不同的迷宫。该测试集不覆盖图形界面行为。

## 局限性

采用离散网格模拟，墙壁静态不变，传感器理想且无噪声。未包含实体硬件、电机或运动学模型。首次探索路线不保证全局最短；到达目标也不意味着已完成整张地图的探索。
